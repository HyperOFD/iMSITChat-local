# iMSITChat для Android

Клиент устанавливается как обычное приложение. На телефоне работают форма входа, список диалогов, переписка и панель администратора. Интерфейс React, стили и шрифты входят в APK. Аккаунты, история и проверка прав находятся на том же сервере FastAPI и PostgreSQL, которым пользуется браузер. Для работы клиенту нужно соединение с компьютером, где запущен Docker Compose.

## Установка и вход

1. Возьмите [iMSITChat.apk](../artifacts/iMSITChat.apk) и установите на Android 8.0 или новее с актуальным Android System WebView. Можно открыть APK на телефоне или выполнить с компьютера `adb install -r artifacts/iMSITChat.apk`.
2. Подключите телефон к серверу по USB или Wi-Fi по инструкции ниже. Для `adb` нужны Android SDK Platform-Tools и включённая на телефоне отладка по USB. Подтвердите подключение этого компьютера на экране телефона.
3. Откройте **iMSITChat**, войдите под существующим именем или зарегистрируйтесь. Ссылка **Адрес сервера** есть на форме входа и экране подключения. После входа адрес меняется кнопкой настроек в верхней панели.

### По USB или на эмуляторе

В каталоге с `compose.yaml`:

```sh
docker compose up -d --wait
adb devices
adb reverse tcp:8080 tcp:8080
```

Оставьте в приложении **http://localhost:8080**. Команда reverse связывает порт 8080 телефона с портом 8080 компьютера. Если устройств несколько, используйте `adb -s СЕРИЙНЫЙ_НОМЕР reverse tcp:8080 tcp:8080`. После переподключения USB или перезагрузки проверьте `adb reverse --list` и при необходимости повторите настройку. Обычный запуск Compose оставляет сервис доступным через loopback.

### Через Wi-Fi

Подключите компьютер и телефон к одной доверенной локальной сети. Узнайте IPv4 компьютера, например `192.168.1.25`. Создайте файл `.env` в корне проекта или дополните существующий одной строкой:

```dotenv
ANDROID_LAN_IP=192.168.1.25
```

Подставьте действительный IP компьютера. Запустите:

```sh
docker compose -f compose.yaml -f compose.android.yaml up -d --wait
```

Откройте **Адрес сервера** и введите, например, **http://192.168.1.25:8080**. Дополнительный файл Compose привязывает порт Nginx к выбранному адресу и добавляет точный origin для API и WebSocket. Имя проекта, тома, аккаунты и история остаются общими. Если задан `CHAT_PORT`, используйте его и в приложении. Чтобы вернуться к доступу только с компьютера или по USB, выполните `docker compose -f compose.yaml up -d --wait`.

Если телефон не видит сервер, откройте в его браузере адрес `http://IP_КОМПЬЮТЕРА:8080/api/health`. Ожидается `{"status":"ok"}`. Проверьте адрес, правила входящих подключений межсетевого экрана и изоляцию клиентов гостевой Wi-Fi-сети. Локальный HTTP передаёт данные без шифрования. Клиент также принимает HTTPS-адрес с доверенным сертификатом. Для такого развёртывания настройте TLS, точный `ALLOWED_ORIGINS` и `COOKIE_SECURE=true` на сервере.

## Поведение приложения

- Вход хранится в HttpOnly cookie WebView. При смене сервера клиент очищает свои cookie, затем открывает выбранный сервер.
- Пока чат открыт, сообщения, присутствие и «Печатает…» обновляются через WebSocket. При сворачивании Android-клиент закрывает соединение. После возврата он переподключается и загружает пропущенные сообщения. Фоновых push-уведомлений в этой версии нет.
- Системная кнопка «Назад» возвращает из диалога или поиска к списку. На экране входа она закрывает приложение.
- Адрес сервера сохраняется на устройстве. Открытый HTTP разрешён для localhost и частных IPv4. Настройки доступа к файлам и content URI в WebView отключены. В поставляемом APK отладка WebView выключена.

## Результат проверки

APK установлен на эмулятор с API 37. На отдельном тестовом сервере проверены переписка между Android и настольным браузером, «Печатает…», присутствие, доставка пропущенного сообщения после возврата, кнопка «Назад», восстановление входа после остановки процесса и выход. Установочная сборка local также прошла вход и подключение WebSocket через виртуальную сеть эмулятора с отключённым adb reverse.

## Сборка из исходников

Потребуются Node.js 22.12+ или 24 с npm, JDK 17 или 21 и Android SDK с Platform 35 и Build-Tools 35.0.0. Укажите путь к SDK через `ANDROID_HOME` или `sdk.dir` в локальном `android/local.properties`. Можно открыть каталог `android` в Android Studio. Gradle Wrapper входит в проект.

```sh
cd frontend
npm ci
cd ../android
./gradlew assembleLocal
```

На Windows используйте `gradlew.bat assembleLocal`. Gradle вызывает сборку интерфейса в режиме Android и упаковывает результат в assets. Установочный файл появится в `android/app/build/outputs/apk/local/app-local.apk`. Для учебной установки сборка local подписывается локальным отладочным ключом Android SDK, отладка самого приложения отключена. Обновление поверх установленной копии требует того же ключа подписи.

Первичная установка SDK, npm-пакетов и зависимостей Gradle требует интернета. При готовых зависимостях работает `./gradlew --offline assembleLocal`.

## Проверка на отдельном стенде

Из корня создайте отдельный Compose-проект, как в [инструкции тестирования](testing.md). Он должен слушать порт 18080. Следующие команды используют тестовый эмулятор или тестовый телефон:

```sh
cd android
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb reverse tcp:18080 tcp:18080
adb shell am start -n ru.imsit.chat/.ChatActivity
```

Выберите в приложении **http://127.0.0.1:18080**. На форме входа оставьте тестовый клиент открытым. Из каталога `frontend` выполните `npx playwright install chromium`, задайте `ANDROID_SERIAL` из `adb devices` и запустите:

```sh
node e2e-android/smoke.mjs
```

Сценарий использует Android WebView установленного debug APK и независимый настольный Chromium. Он создаёт два тестовых аккаунта, проверяет обмен в обе стороны, индикатор набора, уход в фон и получение пропущенного, системную навигацию, сохранение сессии и выход. Для своего Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`.

Интерфейс и REST-запросы в приложении используют один origin. HTML, JS, CSS и шрифты обслуживаются из APK, а вызовы API и WebSocket идут на выбранный сервер. [Загрузка локального контента в Android WebView](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)
