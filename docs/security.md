# Безопасность и границы применения

- Argon2id создаёт отдельную соль при каждом хешировании. Сервер проверяет фиктивный хеш при входе с неизвестным именем. Ошибка входа одинакова для неверного имени и пароля.
- Публичная регистрация создаёт user. Схема отклоняет лишние поля. Администратор создаётся из терминала, пароль вводится скрыто. Выходные схемы разрешают только публичные поля.
- Идентификатор сессии содержит 32 случайных байта. БД хранит SHA-256, владельца и время окончания. Cookie действует 7 суток, имеет HttpOnly, SameSite=Strict и Path=/. Secure включается через COOKIE_SECURE при использовании HTTPS. Выход отзывает именно эту сессию. Другие самостоятельные входы сохраняются.
- Проверка Origin и обязательного пользовательского заголовка защищает все изменяющие запросы, включая регистрацию и вход. CORS разрешает точный перечень origins и credentials. WebSocket отдельно проверяет Origin, при подключении, доставке и heartbeat проверяет действительность сессии.
- Чтение истории и отправка требуют участия в диалоге. Для чужого и отсутствующего диалога возвращается один 404. Роль admin даёт доступ к каталогу пользователей. Доступ к содержимому диалога по-прежнему определяется парой участников.
- Доступ к данным параметризован средствами SQLAlchemy. React отображает текст через JSX, не интерпретируя HTML. Nginx устанавливает CSP, запрет встраивания во фрейм и nosniff. Тело HTTP-запроса ограничено 64 КиБ.
- Скользящие окна в памяти одного процесса считают запросы по адресу клиента. На минуту доступны 600 общих запросов, 30 регистраций и входов суммарно, 120 остальных изменений. Healthcheck исключён. Nginx сам устанавливает X-Real-IP. При NAT несколько клиентов могут иметь общий лимит.
- Структурированный журнал API содержит id запроса, шаблон маршрута, метод и HTTP-статус. При внутренней ошибке добавляется тип исключения. Тело, пароли, cookie, токены и переписка в журнал приложения не выводятся.
- По умолчанию опубликован лишь loopback-порт Nginx. СУБД и FastAPI доступны внутри Docker. Пароль БД генерируется локально, backend монтирует файл только для чтения.

## Ограничения

Реестр соединений и лимиты запросов принадлежат одному worker. Перезапуск обнуляет счётчики и требует переподключения клиентов. Приложение предназначено для локальной учебной демонстрации. История и резервные копии доступны владельцу Docker и администратору БД. Сквозного шифрования нет. Список диалогов загружается целиком, поиск пользователей ограничен 25 результатами. Сообщения, пропущенные при разрыве, остаются в БД. Автоповтор POST с неопределённым результатом не выполняется, чтобы пользователь мог сверить историю перед повторной отправкой.
